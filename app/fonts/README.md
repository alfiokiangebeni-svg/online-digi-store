# Polices

Fichiers générés par `scripts/build-fonts.py` à partir de [google/fonts](https://github.com/google/fonts) :
graisses figées, sous-ensemble latin (français, lingala), sans hinting.

| Fichier                                        | Famille                                 | Graisse  | Préchargée        |
| ---------------------------------------------- | --------------------------------------- | -------- | ----------------- |
| `bricolage-grotesque-700.woff2`                | Bricolage Grotesque (opsz 48, wdth 100) | 700      | oui (titres, LCP) |
| `work-sans-400.woff2`                          | Work Sans                               | 400      | oui (texte)       |
| `work-sans-500.woff2`                          | Work Sans                               | 500      | non               |
| `space-mono-400.woff2`, `space-mono-700.woff2` | Space Mono                              | 400, 700 | non               |
